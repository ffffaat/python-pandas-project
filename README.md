# Python Pandas Sales Analysis

## Overview

This project explores over **2.1 million retail transaction records** using Python and Pandas to identify sales trends, customer demographic patterns, and product purchasing behaviour.

The analysis combines transaction, household demographic, and product datasets to demonstrate practical data manipulation and exploratory data analysis skills.

## Objectives

- Analyse sales trends over time
- Compare monthly and yearly sales performance
- Examine sales patterns across days of the week
- Analyse customer spending by age and income group
- Compare household purchasing behaviour
- Explore product department performance across customer demographics

## Tools & Technologies

- Python
- Pandas
- NumPy

## Analysis Performed

### Data Preparation
Selected relevant columns, optimised data types to reduce memory usage, converted transaction dates into datetime format, and prepared the datasets for analysis.

### Time-Based Analysis
Analysed monthly sales trends, compared sales performance between 2016 and 2017, and examined sales patterns by day of the week.

### Customer Demographics
Aggregated sales at household level and combined transaction data with demographic information including age group, income group, and household composition.

Pivot tables and visualisations were used to compare purchasing behaviour between demographic groups.

### Product Analysis
Combined transaction, demographic, and product datasets to analyse sales across product departments and identify differences in purchasing patterns between age groups.
